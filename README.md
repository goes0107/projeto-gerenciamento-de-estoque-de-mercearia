# projeto-gerenciamento-de-estoque-de-mercearia

Descrição:
	O programa irá coletar dados que o usuário informar, como: nome do produto, quantidade, id do produto, data de validade e data de fabricação. 


Métodos adicionais:
Sistema de devolução
    O sistema permitirá que o cliente devolva produtos comprados, e, em caso de venda de um produto vencido ou danificado, o sistema emitirá uma notificação para verificar o restante do estoque
  
Controle de estoque
    O sistema permitirá que o usuário diminua ou adicione a quantidade do estoque em tempo real  

Organização de estoque
    O sistema permitirá que o usuário receba notificações do que está em excedente e o que está em falta

 Editar e remover produto 
    O sistema permitirá que o usuário edite informações sobre o produto e remova ele, caso necessário

Buscar produto e listar produtos
    O sistema permitirá que o usuário busque produtos, recebendo todas suas informações importantes.
    
Cadastrar e listar fornecedores
    O sistema permitirá que o usuário cadastre e liste fornecedores, pegando seu nome, ativo(boleano) e algum contato
